## Runner-setup import fix (explicit)

The three existing test files registered tests via `node:test`
(`import test from 'node:test'`). Vitest executed the files but collected zero
tests from them ("No test suite found in file"), because the tests were wired to
Node's own test harness rather than Vitest's. This is a pure runner-setup case
(missing-import category), and the mission permits import-path/setup-only edits
for that. The single changed line in each file is the `test` import source:

- `src/modelmixState.test.js`: `import test from 'node:test'` →
  `import { test } from 'vitest'`
- `src/configuredModels.test.js`: same change
- `src/utils/fontSize.test.js`: same change

`import assert from 'node:assert/strict'` was kept in all three files — that is a
plain Node module that works natively inside Vitest's Node workers, so no change
was required. No assertions, no product code, no `modelmixApi.js`, no
`ModelMixObserver.jsx`, and no CSS were touched. The two sibling test files were
converted with the identical one-line fix because `npm test` collects all three
files and the same setup defect otherwise fails the whole run.
